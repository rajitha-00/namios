# NamiOS Public Website

Public marketing website for NamiOS, the hospitality operating platform developed by DesignNetrix.

## Requirements

- Node.js 20 or newer
- npm

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production verification

```bash
npm run lint
npm run build
npm start
```

## Public routes

- `/` — Platform overview
- `/products` — Nami Stay
- `/products/dine`, `/products/people`, `/products/payments`, `/products/portal`, `/products/ai` — Upcoming applications
- `/pricing`, `/benefits`, `/offers`
- `/qa`, `/about`, `/contact`
- `/privacy`, `/terms`

The site uses a self-hosted Quicksand variable font and local optimized WebP media. No runtime environment variables are currently required.
